## ✨ Features

*   **Intelligent Search:** Quickly find movies, genres, or specific themes using the responsive search bar.
*   **Curated Discovery:** Toggle between "Top Picks" for universally acclaimed films and "For You" for tailored suggestions.
*   **Detailed Movie Cards:** Instantly view essential movie data including release year, director, genres, and a brief plot synopsis.
*   **Match Scoring:** Displays a percentage-based "Match" score and star rating to help users gauge how well a movie fits their tastes.
*   **Premium UI/UX:** Built with a modern dark theme, smooth hover effects, and a responsive grid layout for an immersive browsing experience.

## 🛠️ Technologies Used

*   **Frontend Framework:** React with Vite
*   **Language:** TypeScript / JavaScript
*   **Styling:** CSS / Tailwind CSS
*   **AI Engine:** Google Gemini API 

## 🚀 Getting Started

Follow these instructions to set up the project locally on your machine.

### Prerequisites

*   Node.js installed on your machine
*   A Google Gemini API Key

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nitinsaini1805/Movie-Recommendation-System.git
   cd Movie-Recommendation-System
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Environment Setup:**
   * Create a new file named `.env` in the root directory of your project.
   * Add your Gemini API key to this file:
     ```env
     GEMINI_API_KEY=your_actual_api_key_here
     ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
